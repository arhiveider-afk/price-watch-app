# Цена под контролем — прототип

Мобильный интерфейс для отслеживания цены и наличия товаров.

## Запуск на ноутбуке

В PowerShell из этой папки:

```powershell
node server.js
```

Откройте `http://localhost:8787`. Сервер также выведет LAN-адрес — его можно открыть на телефоне в той же Wi-Fi сети. Для остановки нажмите `Ctrl+C` в окне сервера.

Техническая проверка: откройте `http://localhost:8787/api/health`; ответ должен содержать `"ok":true`.

Что уже работает локально:

- карточка отслеживаемого товара;
- добавление и редактирование подписки;
- регион, ценовой порог и три переключателя уведомлений;
- приостановка и удаление подписки;
- сохранение состояния в `localStorage`.

## Перед выпуском Android/iOS

Клиент не должен опрашивать Ozon самостоятельно: мобильные ОС не обеспечивают регулярные фоновые запросы каждые 5–10 минут. Локальный сервер уже запускает планировщик раз в 10 минут, но пока использует безопасный заглушечный адаптер `waiting_for_ozon_adapter`. Нужен разрешённый способ получения данных Ozon и push через FCM/APNs.

Контракт проверки, который должен реализовать сервер:

```json
{
  "productId": "ozon-card-id",
  "region": "Москва",
  "price": 19990,
  "inStock": true,
  "url": "https://www.ozon.ru/product/..."
}
```

Уведомление отправляется, когда `inStock=true` и `price <= limit`, либо при переходе `inStock: false → true`, если этот переключатель включён. Для релиза этот интерфейс можно упаковать через Capacitor, а затем подключить FCM и APNs.
